# GitCode CLI v0.10.0

v0.10.0 新增飞书/Lark 集成（`gc lark` 命令组），可向飞书群或自己发送通知，面向 AI 代理与脚本自动化。

## 新增

- `gc lark` 命令组：通过官方 `lark-cli` 子进程委托与飞书/Lark 集成。飞书 OAuth 凭证由 `lark-cli` 存入操作系统 keychain，`gc` 不读取、不打印、不日志记录飞书令牌。
  - `gc lark send`：发送消息，目标三选一（互斥）——`--to-self`（给自己，自动解析当前用户 open_id，默认 bot 身份，无需群、不受外部群限制）、`--user-id ou_xxx`（单聊）、`--chat-id oc_xxx`（群）。内容支持 `--text`/`--markdown`/`--file`/`--body-file`（`-` 表示 stdin）。
  - `gc lark auth status`：查看 `lark-cli` 登录状态（`--json` 透传结构化输出）。
  - `gc lark install`：运行官方安装器 `npx @larksuite/cli@latest install`（首次运行 lazy 检测）。
  - `gc lark doctor`：检测 `lark-cli` 安装 + 登录就绪 + 默认群配置。
  - `gc lark config set|get --default-chat`：管理默认群（持久化到 `~/.config/gc/lark.json`，权限 0600）。
- 安全：`gc lark send` 正文经 `cmdutil.ScanContentForSecrets` 扫描，含当前 `GC_TOKEN`/`GITCODE_TOKEN` 值则拒绝发送；`lark-cli` 子进程不继承 `gc` 的 stdin，且环境中的 `GC_TOKEN`/`GITCODE_TOKEN` 被剥离。
- 退出码：认证/权限/scope/群成员类失败映射为 exit 4；其余 lark-cli 失败 exit 1；参数错误 exit 2。

## 安装

### Homebrew (macOS/Linux)

```bash
brew install gitcode-cli/homebrew-tap/gc
brew upgrade gc
```

### Wheel（跨平台）

```bash
pip install https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.0/gitcode_cli-0.10.0-py3-none-any.whl
gitcode version
```

### Debian / Ubuntu

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.0/gc_0.10.0_amd64.deb
sudo dpkg -i gc_0.10.0_amd64.deb
```

### RHEL / CentOS / Fedora

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.0/gc-0.10.0-1.x86_64.rpm
sudo rpm -i gc-0.10.0-1.x86_64.rpm
```

### 飞书通知首次配置（v0.10.0 新增能力）

```bash
gc lark install                          # 安装 lark-cli
lark-cli config init --new               # 配置飞书应用（交互，浏览器）
lark-cli auth login --recommend          # OAuth 登录（交互，浏览器）
gc lark doctor                           # 验证安装+登录
gc lark send --to-self --text "hello"    # 给自己发通知
```

完整指南见 `docs/LARK.md`。
