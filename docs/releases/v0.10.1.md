# GitCode CLI v0.10.1

v0.10.1 补丁版新增 **npm 分发渠道**，GitCode CLI 可经 `npx @gitcode-cli/cli@latest install` 或 `npm i -g @gitcode-cli/cli` 一行安装，覆盖 Node-first 用户与纯 node CI 镜像。本版本不改变 gc 命令行为，仅新增分发渠道。

## 新增

- **npm 包 `@gitcode-cli/cli`**（scoped，归 `gitcode-cli` npm 组织）：内置 Linux x64/ARM64、macOS x64/ARM64、Windows x64 多平台二进制，Node wrapper 按平台选择并 exec，`gc`/`gitcode` 两个入口。
  - `npx @gitcode-cli/cli@latest install`：一行 bootstrap——把二进制装到全局 bin（`/usr/local/bin` 可写则用，否则 `~/.local/bin`，Windows 下给 `setx PATH` 指引）+ `gitcode` 软链 + 自动装 bash/zsh/fish 补全（`gc completion`）。
  - `npm i -g @gitcode-cli/cli`：全局安装，`gc` 直接可用。
- release workflow 新增 `npm` job：交叉编译 5 二进制（含版本 ldflags）+ 同步 `npm/package.json` 版本 + `npm pack`/单测 + `npm publish --access public`（引用 `NPM_TOKEN` secret；重跑时 `npm view` 校验已存在则幂等跳过）。所有 action SHA-pinned。
- 安全：npm 包不含凭证；`NPM_TOKEN` 不入日志（GitHub masked + `~/.npmrc` 临时写入）；二进制由 workflow 从源码构建，非外部下载。

## 安装

### npm（跨平台，新增）

```bash
# 一行 bootstrap（无需全局 npm 安装）
npx @gitcode-cli/cli@latest install

# 或全局安装
npm install -g @gitcode-cli/cli
gc version
```

### Homebrew (macOS/Linux)

```bash
brew install gitcode-cli/homebrew-tap/gc
brew upgrade gc
```

### Wheel（跨平台）

```bash
pip install https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.1/gitcode_cli-0.10.1-py3-none-any.whl
gitcode version
```

### Debian / Ubuntu

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.1/gc_0.10.1_amd64.deb
sudo dpkg -i gc_0.10.1_amd64.deb
```

### RHEL / CentOS / Fedora

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.1/gc-0.10.1-1.x86_64.rpm
sudo rpm -i gc-0.10.1-1.x86_64.rpm
```
