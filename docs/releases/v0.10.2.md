# GitCode CLI v0.10.2

v0.10.2 补丁版**正式上线 npm 分发渠道**（v0.10.1 的 npm job 因测试环境相关性失败，本版本修复并完成首次 `npm publish`）。GitCode CLI 现可经 `npx @gitcode-cli/cli@latest install` 或 `npm i -g @gitcode-cli/cli` 安装。

## 新增

- **npm 包 `@gitcode-cli/cli` 首次发布**：内置 Linux x64/ARM64、macOS x64/ARM64、Windows x64 多平台二进制，Node wrapper 按平台选择并 exec，`gc`/`gitcode` 两个入口。
  - `npx @gitcode-cli/cli@latest install`：一行 bootstrap——把二进制装到全局 bin（`/usr/local/bin` 可写则用，否则 `~/.local/bin`，Windows 给 `setx PATH` 指引）+ `gitcode` 软链 + 自动装 bash/zsh/fish 补全。
  - `npm i -g @gitcode-cli/cli`：全局安装，`gc` 直接可用。
  - release workflow `npm` job 交叉编译 5 二进制 + 同步版本 + `npm pack`/单测 + `npm publish --access public`（幂等校验）。

## 修复

- npm wrapper/install 单测改为**确定性**：`gc.js` 的 `PLATFORMS_DIR` 支持 `GC_PLATFORMS_DIR` 环境覆盖，`wrapper.test.js` 用空目录确定性触发 ENOENT；`install.test.js` 断言"可写+存在"不变量而非绑定 `/usr/local/bin`。修复 v0.10.1 release workflow 中 npm job 的 verify 步失败。

## 安装

### npm（跨平台，本版本首发）

```bash
npx @gitcode-cli/cli@latest install
# 或
npm install -g @gitcode-cli/cli
gc version
```

### Homebrew (macOS/Linux)

```bash
brew install gitcode-cli/homebrew-tap/gc
brew upgrade gc
```

### Wheel（跨平台）

```bash
pip install https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.2/gitcode_cli-0.10.2-py3-none-any.whl
gitcode version
```

### Debian / Ubuntu

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.2/gc_0.10.2_amd64.deb
sudo dpkg -i gc_0.10.2_amd64.deb
```

### RHEL / CentOS / Fedora

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.2/gc-0.10.2-1.x86_64.rpm
sudo rpm -i gc-0.10.2-1.x86_64.rpm
```
