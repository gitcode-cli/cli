# GitCode CLI v0.10.3

v0.10.3 补丁版**修复 npm 包的 bin shim**并**正式以 OIDC Trusted Publishing 从 release workflow 发布 npm**。`npx @gitcode-cli/cli@latest install` 与 `npm i -g @gitcode-cli/cli` 现可正常使用。

> `@gitcode-cli/cli@0.10.2` 因 `bin/gc.js` 缺 shebang 导致 npm bin shim 失败，已被 `0.10.3` 取代（建议对 0.10.2 执行 `npm deprecate`）。

## 修复

- **npm bin shebang**：`npm/bin/gc.js` 首行加 `#!/usr/bin/env node`（并设可执行位）。原缺 shebang 导致 npm 的 `node_modules/.bin/gc` shim 把 gc.js 当 shell 脚本执行（`//` 注释报错），`npx ... install` 与 `npm i -g ... && gc` 均失败。
- **npm 发布改用 OIDC Trusted Publishing**：release workflow `npm` job 用 `permissions: id-token: write` + `actions/setup-node`（Node 24）+ `npm publish`，npm CLI 自动经 OIDC 短期令牌发布，**无 NPM_TOKEN**，自动生成 provenance。`npm/package.json` 的 `repository.url` 改为 `https://github.com/gitcode-cli/cli.git`（OIDC 校验）。npm Classic token 已于 2025-11 移除，granular token 无法创建 org 下首个新包，故用 OIDC。

## 安装

### npm（跨平台，本版本首发可用）

```bash
npx @gitcode-cli/cli@latest install
# 或
npm install -g @gitcode-cli/cli
gc version
```

### Homebrew (macOS/Linux)

```bash
brew install gitcode-cli/homebrew-tap/gc
brew upgrade gc
```

### Wheel（跨平台）

```bash
pip install https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.3/gitcode_cli-0.10.3-py3-none-any.whl
gitcode version
```

### Debian / Ubuntu

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.3/gc_0.10.3_amd64.deb
sudo dpkg -i gc_0.10.3_amd64.deb
```

### RHEL / CentOS / Fedora

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.10.3/gc-0.10.3-1.x86_64.rpm
sudo rpm -i gc-0.10.3-1.x86_64.rpm
```
