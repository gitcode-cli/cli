# GitCode CLI v0.9.1

v0.9.1 补丁版新增 Homebrew (macOS/Linux) 安装方式，完善发布安装链路。

## 新增

- Homebrew (macOS/Linux) 安装：GoReleaser 生成 formula，发布流程自动推送到 `gitcode-cli/homebrew-tap`，支持 `brew install` 与 `brew upgrade`，shell 补全（bash/zsh/fish）随安装自动配置。

## 改进与修复

- 修正 `homebrew/gc.rb` 模板 URL 与制品命名，对齐 archive 命名规则。
- 修正 `CONTRIBUTING.md` Homebrew tap 路径（`gitcode-com/tap` → `gitcode-cli/homebrew-tap`）。
- 发布流程规范同步 Homebrew formula 推送步骤与发布后验证。

## 安装

### Homebrew (macOS/Linux，新增)

```bash
brew install gitcode-cli/homebrew-tap/gc
brew upgrade gc
```

### Wheel（跨平台）

```bash
pip install https://gitcode.com/gitcode-cli/cli/releases/download/v0.9.1/gitcode_cli-0.9.1-py3-none-any.whl
gitcode version
```

### Debian / Ubuntu

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.9.1/gc_0.9.1_amd64.deb
sudo dpkg -i gc_0.9.1_amd64.deb
```

### RHEL / CentOS / Fedora

```bash
wget https://gitcode.com/gitcode-cli/cli/releases/download/v0.9.1/gc-0.9.1-1.x86_64.rpm
sudo rpm -i gc-0.9.1-1.x86_64.rpm
```
